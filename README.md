# MyMouseMyControl

**MyMouseMyControl** 是一款 macOS 菜单栏工具，让你自由定制鼠标侧键（第 4、5 键）的功能，支持复制、粘贴、撤销、调度中心等十余种快捷操作，并支持开机自启动。

---

## 功能特性

- 🖱️ **自定义侧键动作** — 为鼠标侧键 4 和侧键 5 分别绑定不同操作
- ⌨️ **丰富的快捷键支持** — 复制、粘贴、剪切、撤销、重做、全选、保存、前进、后退、调度中心、启动台、切换/关闭/新建标签页
- 🔔 **菜单栏常驻** — 不占 Dock，轻量后台运行，随时查看监听状态
- 🚀 **开机自启动** — 一键开启，登录后自动运行
- 💾 **配置持久化** — 按键绑定自动保存，重启后保持设置

---

## 系统要求

- macOS 14.0 (Sonoma) 及以上
- 需要授予**辅助功能权限**（系统设置 → 隐私与安全性 → 辅助功能）

---

## 安装

### 方式一：下载 Release（推荐）

1. 前往 [Releases](../../releases) 页面，下载最新的 `.zip` 文件
2. 解压后将 `MyMouseMyControl.app` 拖入「应用程序」文件夹
3. 首次启动时，按提示前往系统设置授予辅助功能权限

### 方式二：从源码编译

```bash
git clone https://github.com/xzj2004/MyMouseMyControl.git
cd MyMouseMyControl
open MyMouseMyControl.xcodeproj
```

在 Xcode 中选择 `My Mac` 目标，按 `⌘R` 运行。

---

## 使用说明

1. 启动应用后，菜单栏右上角会出现鼠标图标 `⌖`
2. 首次使用点击「授权」按钮，跳转到系统设置开启辅助功能权限
3. 权限授予后自动开始监听，状态显示「监听中 ●」
4. 在设置界面通过下拉菜单为侧键 4、侧键 5 选择所需动作
5. 开启「开机自启动」后，登录 Mac 时自动启动

## 支持的动作列表

| 动作 | 快捷键 |
|------|--------|
| 复制 | ⌘C |
| 粘贴 | ⌘V |
| 剪切 | ⌘X |
| 撤销 | ⌘Z |
| 重做 | ⌘⇧Z |
| 全选 | ⌘A |
| 保存 | ⌘S |
| 返回 | ⌘[ |
| 前进 | ⌘] |
| 调度中心 | ⌃↑ |
| 启动台 | F4 |
| 切换标签页 | ⌃Tab |
| 关闭标签页 | ⌘W |
| 新建标签页 | ⌘T |
| 无动作 | — |
